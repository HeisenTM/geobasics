Learn Common Languages

You don't need to speak a language to spot it. Check the alphabet, then the special letters, then a few common words.

  1. Check the alphabetLatin (like English), Cyrillic, Greek, Arabic, or something else.
  2. Look for special lettersLetters like ñ, ß, ø or ł point to one language straight away.
  3. Read the common wordsStreet, road and exit signs use the same few words again and again.

Languages cross borders

Many countries use more than one language, and tourist areas often add English. Use language as one clue, then combine it with road lines, driving side and landscape.
